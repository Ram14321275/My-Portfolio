# Ram Pawar — AI Solutions Architect & Creative Designer

Welcome to my personal portfolio repository! This is a high-end, premium web experience crafted to showcase my work as an AI Solutions Architect, Graphic Designer, and Artist. It features immersive 3D interactions, smooth scrolling, and dynamic micro-animations.

🌐 **Live Website**: [github.com/Ram14321275/My-Portfolio](https://github.com/Ram14321275/My-Portfolio) (or local `http://localhost:3000`)

---

## 🚀 Key Features

*   **Immersive 3D Experiences**: Powered by **Three.js** and **React Three Fiber**, rendering a custom 3D interactive portrait and floating tool/skills spheres with explosion physics.
*   **Asset-Tracking Loading Screen**: Custom loading screen that monitors page asset loading (HTML images and Three.js textures) to guarantee a smooth and fully rendered load.
*   **Vibrant Motion & Micro-Animations**: Built with **GSAP (ScrollTrigger)** and **Framer Motion** for premium deceleration transitions, reveals, and interactive elements.
*   **Buttery-Smooth Physics Scrolling**: Integrated with **Lenis** to provide high-quality inertial scrolling across the landing page.
*   **Responsive Pill Navbar**: An adaptive header navigation menu that transforms into a condensed floating pill header when scrolled.

*   `src/components/animations/` — Loading screen, smooth scroll context, and animated text assets.

## ⚡ Getting Started

### Prerequisites

*   Node.js (v18+ recommended)
*   npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Ram14321275/My-Portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd My-Portfolio
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally

To start the local development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
